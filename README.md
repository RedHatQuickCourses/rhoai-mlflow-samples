# rhoai-mlflow-samples

Sample code, scripts, and manifests for the Red Hat Product Enablement Team quick courses about MLflow:

* [Agent Traces with MLflow and Red Hat OpenShift AI](https://github.com/RedHatQuickCourses/rhoai-mlflow-traces)
* [Agent Evaluations with MLFLow and EvalHub on Red Hat OpenShift AI](https://github.com/RedHatQuickCourses/rhoai-mlflow-evals)

This repository contains an Antora playbook and modules directories so it can be used directly as a content source for `include::` macros.
